# Radio Italo

Radio Italo är en responsiv webbplats för personer som vill upptäcka eller återupptäcka Italo disco. Besökare kan läsa om musikgenren, upptäcka utvalda låtar och artister samt även lyssna på musiken direkt på webbplatsen.

## Syfte

Projektets syfte är att lyfta faram och väcka intresse för musiken. Webbplatsen visar även upp kunskaper inom **HTML**, **CSS** och **JavaScript**.

## Innehåll

- Introduktion till musikgenren.
- Presentationer av utvalda låtar och artister tillsammans med inbäddade Youtube-spelare.
- Responsiv layout för större och mindre skärmstorlekar.
- Mobilmeny som öppnas och stängs med hjälp av JavaScript.
- Kontaktformulär som valideras med JavaScript.

## Tekniker

- **HTML** för innehåll och struktur.
- **YouTube-iframe** för att bädda in musiken.
- **CSS** för layout, typografi, färger och anpassning för olika skärmstorlekar.
- **JavaScript** för mobilmeny och validering av kontaktformulär.

## Design

Layouten planerades med hjälp av wireframes för dator och mobil.

## Begränsningar

Kontaktformuläret skickar ej meddelanden till någon mottagare.

## Musik och rättigheter

Musiken på webbplatsen spelas upp via Youtubes inbäddade spelare och tillhör respektive rättighetsinnehavare. Projektet lagrar alltså inga egna video- eller ljudfiler.
